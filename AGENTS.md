# Anishelf

- Code changes must pass the Biome check.
- Follow the [code style constraints](docs/development/code-style.md).
- Write document in English.
- Prefer well-established libraries over custom implementations whenever possible. Feel free to add new dependencies when necessary.
- Some tests require permissions to spwan child process and listen on localhost. If you wish to run these tests, please do so in an environment where these operations are permitted.
- Provide a Git commit in chat window when changing code. Don't commit.
- Review the [UI design docs](docs/development/design-system.md) and reference existing pages before changing the UI.
- Remember to add logs
